# 单词手记

从学习桌打开「背词工具」，入口仍为 `/vocab.html`。本模块沿用当前部署的单用户登录，不提供多用户隔离。

## 一次完整使用

1. 粘贴英文文章，点击「提取并查词」。普通提取只读取服务器上的 ECDICT，不调用模型。
2. 每个词条保留出现次数、原文词形和最多三条来源原句。支持常见弯撇号缩写和连字符词；词典含 exchange 字段时展示原形关系，但不擅自合并不同词义。
3. 默认显示「英文释义 · 中文辅助」。优先显示 AI / 手动解释；尚未生成时显示带来源标注的词典英文，不将它标为已简化。词典英文缺失时明确提示；完整词典原文仍可展开。中文和英文缺失分别提示，不把空字段写成“整词未收录”。词典不可读或表结构异常会使本次提取失败。
4. 点击词条的「AI 解释」，按当前选定原句生成中英文解释。选择「更易懂 / 更详细」解释方式；只在主动点击时调用已配置的文字模型，使用现有并发预算和账号限流。
   缺少来源原句的旧词条可点击「补充原句并 AI 解释」，填写包含该词的原句后生成。文章过期或正在生成时会显示原因；调用失败的错误会显示在对应词条旁。提取接口未返回 examples 字段时提示重启后端、刷新并重新提取。
5. AI 内容标为「AI 补充」，可手动填写或修改。词典原文始终保留。模型无法可靠判断词义或返回不完整内容时明确报错，不填充虚构成功结果。
6. 勾选生词并加入生词本。保存的是当前原句及其对应解释；同词同原句去重，重复保存更好的解释不会重置复习进度。同词不同语境可分别保存。
7. 在「今日复习」先回想，再展开释义，自评不会/模糊/掌握。基础规则为不会 10 分钟后、模糊 1 天后、连续掌握按 1/3/7/14/30 天递增。它是初始产品规则，不宣称为已验证的个体最优间隔。
8. Word 导出可选择当前筛选、全部已勾选、当前视图全部，且与显示模式一致。导出当前词条快照；不会因为文本框后来修改而悄悄换一份词表。

文章修改后旧结果标为过期，重新提取前禁止保存/导出；清空或替换文章会忽略迟到的提取响应。AI 迟到响应也不会覆盖新的手动修改。

## 保存与隐私

- 文章草稿保存在当前浏览器 localStorage（兼容旧键 `vocab.article.v1`），未保存的提取结果与 AI 解释刷新后需要重新生成。
- 生词及复习历史保存在服务器 `data/vocab/notebook.json`，与 Agent 长期记忆分开，不受记忆遗忘淘汰影响；同一部署的同一账号可跨设备读取。
- `FA_VOCAB_NOTEBOOK_FILE` 可覆盖默认保存路径。如果改到 `data/` 外面，需要自行把该目录加入备份；默认路径已被现有 data 备份覆盖。
- 仅主动 AI 解释时发送选中词条、选用原句和少量词典参考到已配置模型服务；不会自动发送整篇文章。
- 原始词典以只读 SQLite URI 打开；正常查词只读，不修改词典。
- 释义缓存为服务进程内最多 256 项，区分词、原句、难度及词典参考内容，重启清空；已保存到生词本的解释不会因重启丢失。

## 初版边界

- 文章最多 100000 字符，最多 5000 个不同词条（沿用 `FA_VOCAB_MAX_WORDS`）；单次加入生词本最多 100 条，生词本最多 1000 条、文件最多 16 MB。
- 每条保留总复习次数和最近 20 次反馈。基础排序/标签筛选不代表词汇学习难度的科学评估。
- AI 用常见词和短句的要求写入提示词并检查完整性/长度，但解释的真实正确性与易读度仍需真实模型使用和人工核对，不能仅凭模拟测试宣称质量达标。
- 未自动补全整篇文章，未引入外部在线词典、语音订阅或新模型依赖。
- 生词本采用单进程同步锁和临时文件替换，适用于当前单实例部署；多个实例共享同一 JSON 文件不受支持。

## API

全部业务端点需要登录；POST/PATCH/DELETE 保持 CSRF 保护。

| 方法与路径 | 功能 |
| --- | --- |
| `POST /api/vocab/extract` | `{article}` → 词表、频次、原句、词形与缺失状态 |
| `POST /api/vocab/explain` | `{word, example, level}` → 标注来源的解释；共用模型预算及限流 |
| `POST /api/vocab/docx` | `{words, mode}` → 按快照导出；兼容旧 `{article, mode}` 请求 |
| `GET /api/vocab/book` | 生词列表与服务器时间 |
| `POST /api/vocab/book` | `{words}` → 保存，按单词与原句去重 |
| `PATCH /api/vocab/book/{id}` | 更新词条解释，保留复习记录 |
| `POST /api/vocab/book/{id}/review` | `{rating: again|hard|good}` → 记录反馈与下次复习时间 |
| `DELETE /api/vocab/book/{id}` | 用户确认后移出该条生词及其复习记录 |
